# Five-Minute Demo Script

## 0:00–0:40 — Problem
Explain that primary-care teams can struggle to see which follow-ups remain unresolved and whether referrals have a recorded outcome. Use a fictional scenario only.

## 0:40–1:20 — Solution
Show CareRoute's dashboard and explain that the work queue surfaces administrative tasks, not medical diagnoses.

## 1:20–3:20 — Live workflow
1. Search for CR-1002.
2. Open Follow-ups and explain its overdue flag and source date.
3. Create a follow-up for a fictional patient.
4. Mark a task completed and show dashboard recalculation.
5. Create a referral and update its status.
6. Change the overdue threshold in Rules and show the explanation.

## 3:20–4:10 — Trust and architecture
Explain synthetic-only data, the local demo limitation, intended database/auth architecture, and need for reviewed server-side access control before real use.

## 4:10–5:00 — Startup next step
Describe target users as hypotheses, propose discovery interviews, and ask for access to workflow feedback—not real patient records.

## Backup
Have screenshots and a short screen recording ready in case internet or deployment fails. Never present unmeasured outcomes as achieved results.
