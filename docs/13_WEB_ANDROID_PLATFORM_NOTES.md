# Platform Notes

## Current target
Responsive web application. The 48-hour MVP does not include a native Android app.

## Why web first
A browser app is easier to share with reviewers, iterate quickly, and use across laptops and phones. Validate the workflow before investing in a native client.

## Future Android considerations
If demand is validated, evaluate a responsive progressive web app first. A native Android app requires secure token storage, app lifecycle handling, accessibility, update/release management, device-loss considerations, and careful offline-sync conflict resolution. Do not store sensitive health records unencrypted in local app storage.
