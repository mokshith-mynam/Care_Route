# UX and Accessibility Notes

- Keep the main navigation predictable: Overview, Patients, Follow-ups, Referrals, Rules.
- Show status text, not color alone.
- Every flag should explain why it appeared and which recorded date/status caused it.
- Distinguish overdue, due today, completed, rescheduled, and unknown outcomes.
- Do not imply that a missed update means the patient missed care.
- Use visible keyboard focus, semantic headings, labels, accessible dialog names, and responsive tables.
- Test at narrow mobile widths and desktop widths; test keyboard-only navigation.
- Prefer plain language for nontechnical users; avoid clinical judgments in administrative labels.
- Respect reduced-motion settings and maintain sufficient contrast.
