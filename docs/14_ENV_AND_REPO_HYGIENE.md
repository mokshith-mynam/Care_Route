# Environment and Repository Hygiene

- Copy `.env.example` to `.env` only for local configuration.
- Never commit `.env`, API secrets, service-role keys, production exports, or private certificates.
- Only public client keys intended for browser use may appear in frontend configuration; database policies must still enforce authorization.
- Pin dependencies with the committed lockfile generated by `npm install`.
- Review dependency updates and remove unused packages.
- Use separate development, test, and production projects.
- Use synthetic data in all non-production environments.
- Rotate credentials immediately if exposed; deleting a commit does not revoke a credential.
