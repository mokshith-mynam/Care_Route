# CareRoute 48-Hour Build Plan

## Team split
- Frontend: dashboard, directory, forms, responsive UI.
- Data/security: schema, synthetic records, auth/RLS design, integration checks.
- Workflow/demo: status transitions, rules, test cases, pitch and demo rehearsal.

## Timeboxes
- Hours 0–3: freeze scope, schema, states, Git workflow.
- Hours 3–9: scaffold app, seed data, dashboard shell.
- Hours 9–17: patient and screening records.
- Hours 17–25: follow-ups and referrals.
- Hours 25–32: rules and permission design.
- Hours 32–39: usability, error states, bug fixes.
- Hours 39–44: deploy and smoke test.
- Hours 44–48: rehearse, screenshots, final pitch.

## Cut line
If behind schedule, remove advanced charts and optional settings. Preserve the end-to-end follow-up workflow, referral status updates, transparent rule explanations, synthetic data, and a credible safety disclaimer.
